# idea-hub

아이디어를 입력하고 의미가 비슷한 아이디어를 그룹화하는 팀 프로젝트입니다. 개발은 각자의 컴퓨터에서 진행하고 GitHub로 코드를 합칩니다.

## 프로젝트 구성

- `frontend/` — 보드 화면과 아이디어 카드
- `backend/` — 서버, API, 데이터 저장
- `ai/` — 아이디어 분석과 그룹화

현재 저장소에는 협업을 위한 기본 구조가 준비되어 있습니다. 각 기능과 실행 방법은 담당자가 구현하면서 추가합니다.

## 팀 협업 방법

1. 저장소 관리자가 팀원들을 GitHub 저장소에 초대합니다.
2. 각자 저장소를 자신의 컴퓨터에 복사합니다.
3. 최신 `main`에서 `feature/board-ui`처럼 기능별 브랜치를 만듭니다.
4. 작업을 커밋하고 GitHub에 올린 뒤 Pull Request를 생성합니다.
5. 팀원이 변경 내용을 확인하고 `main`에 합칩니다. 다음 작업 전에 최신 `main`을 받아옵니다.

각자 로컬 SQLite 파일과 테스트 데이터는 공유되지 않습니다. 비밀번호, API 키, 개인 `.env` 파일과 모델 가중치는 Git에 올리지 않습니다.

## 자동화 확인

코드가 올라오면 GitHub Actions가 Python 파일의 문법을 확인합니다. 기능이 구현되면 실제 테스트와 프론트엔드 빌드 명령을 워크플로에 추가합니다. 현재 워크플로의 성공은 전체 기능이 완성되었음을 뜻하지 않습니다.

## 담당 영역

- 이재환: 보드 화면, 공통 UI, 발표 자료
- 최양환: 아이디어 카드와 그룹 조작
- 이승창: DB, API, 시스템 통합
- 이승혁: 의미 분석과 그룹화
