# 팀원 확인 목록 — 화면 시안 ↔ API 비교

화면 시안(README의 각 화면)이 서버에 무엇을 요구하는지, 지금 API에 그게 있는지 나란히 적었습니다.
기준: `docs/api-db-contract.md`(P2 명세)와 열려 있는 B2 PR #5(보드·카드 API, 2026-11-23 기준).

- ✅ 있음 · 🟡 명세에만 있고 아직 구현 전 · ❌ 없음(정해야 함)
- 각자 자기 담당 줄을 보고, PR에 댓글로 "괜찮음 / 바꾸자 / 질문"을 남겨 주세요.

## 이승창 (DB · API)

| 화면 | 필요한 것 | 지금 | 확인할 점 |
|---|---|---|---|
| 내 보드 목록 | 보드마다 메모 수, 주제 수, 분류 상태, 최근 수정 시각 | ❌ `GET /boards`는 보드 정보(id, title, 시각)만 줌 | 목록 응답에 개수·상태를 넣을지, 아니면 화면에서 빼고 단순하게 갈지 |
| 내 보드 목록 | 최근 수정한 보드가 위로 | ❌ 지금은 id 순 | `ORDER BY updated_at DESC`로 바꿔도 되는지 |
| 새 보드 | 이름 1~40자 | 🟡 빈 이름은 막지만 길이 제한 없음 | 최대 길이를 정할지(시안 40자) |
| 보드 이름 바꾸기 | `PATCH /boards/{id}` | ❌ 명세에 없음 | 추가할지, 화면에서 뺄지 |
| 보드 삭제 | `DELETE /boards/{id}` | ✅ | — |
| 없는 보드 | 404 | ✅ "보드를 찾을 수 없습니다." | — |
| 메모 쓰기·고치기·지우기 | `POST/PATCH/DELETE /boards/{id}/ideas` | ✅ | — |
| 이미 지워진 메모 | 404 | ✅ "아이디어를 찾을 수 없습니다." | — |
| 메모 위치·표시·펜 | 메모의 x, y / 별 표시 / 펜 그림 저장 | ❌ DB에 칸 없음 | 필드를 추가할지, 자동 정렬로 바꾸고 기능을 뺄지 (최양환과 같이) |
| 분류하기 | `POST /boards/{id}/analyze`, 진행·성공·실패 | 🟡 명세에만 있음 | 실패 시 기존 보드 유지(명세 7절)대로 구현하는지 |
| 로그인·회원가입 | users 테이블, `boards.user_id`, 비밀번호 해시, 로그인 유지(세션 또는 토큰) | ❌ 명세에 없음(PRD 미결) | 이번 학기 범위에 넣을지부터 결정 |
| 복구 코드 | 해시로 저장, 한 번 쓰면 새 코드 발급, 틀린 횟수 제한 | ❌ | 로그인을 넣는다면 같이 |
| 로그인 만료 | 401 응답 | ❌ | 로그인을 넣는다면 같이 |
| 계정 설정·탈퇴 | 이름·비밀번호 변경, 탈퇴 시 내 보드 삭제 | ❌ | 로그인을 넣는다면 같이 |

## 최양환 (카드 · 그룹 조작)

| 화면 | 확인할 점 |
|---|---|
| 메모 쓰기 (`index.html?state=new`) | Enter = 메모지로 붙기, Shift+Enter = 줄바꿈, 빈 곳 두 번 누르기 = 그 자리에서 쓰기. 카드 입력 방식이 생각한 것과 맞는지 |
| 메모 옮기기 (`index.html?state=groups`) | 메모를 눌러 다른 주제로 옮기면 "고정". 카드·그룹 조작 계획과 맞는지, 그룹명 수정·그룹 만들기·그룹 삭제 화면이 필요한지 |
| 메모 위치·표시·펜 | 자유 배치를 유지할지(DB 필드 필요), 자동 정렬로 갈지 — 이승창과 같이 결정 |
| 경계 나누기 | 메모지 컴포넌트(쓰기·고치기·삭제·옮기기) 중 어디까지가 카드 담당이고 어디부터가 보드 화면 담당인지 |

## 이승혁 (의미 분석 · 그룹화)

| 화면 | 확인할 점 |
|---|---|
| 분류 결과 (`index.html?state=groups`) | 시안은 주제가 6개로 고정이지만 실제로는 AI가 그룹 수와 이름을 정함. 그룹이 너무 많아질 때 최대 개수를 둘지, 그룹 이름 길이를 제한할지 |
| 분류 중 | 분류에 걸리는 시간. 메모 50개 기준으로 몇 초 걸리는지(시안은 "묶는 중이에요" 표시만) |
| 분류 실패 (`?state=analyzefail`) | 모델이 실패하거나 시간이 너무 걸릴 때 서버에 어떤 오류로 알려 줄지 |
| 미분류 | 어디에도 안 맞는 메모를 미분류로 두는 기준(유사도 임계값) |

## 다 같이

- 로그인·계정 기능을 **이번 학기 범위에 넣을지** (넣으면 API·DB 작업이 커짐)
- 메모를 **자유 배치**로 할지 **자동 정렬**로 할지
- 보드 이름 바꾸기, 그룹명 수정 등 명세에 없는 화면을 넣을지 뺄지
