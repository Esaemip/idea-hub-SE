# Idea Hub 프런트엔드

아이디어 카드 담당 범위(U1~U6)를 React + TypeScript로 구현한 보드입니다.

화면 흐름 시안은 [`docs/design/board-ui/`](../docs/design/board-ui/)에서 확인할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

기본값은 브라우저 `localStorage`에 저장되는 로컬 모드입니다. 백엔드를 연결하려면 먼저 백엔드에서 보드를 생성한 다음 `.env.example`을 `.env.local`로 복사하고 API 주소와 생성된 보드 ID를 설정합니다.

```powershell
Invoke-RestMethod -Method Post -Uri http://localhost:8000/boards -ContentType 'application/json' -Body '{"title":"새로운 아이디어 보드"}'
Copy-Item .env.example .env.local
```

응답의 `id`를 `.env.local`의 `VITE_BOARD_ID`에 입력합니다. 환경 파일을 바꾼 뒤에는 개발 서버를 다시 시작해야 합니다.

## 구현 범위

화면 배치와 사용 흐름은 [`docs/design/board-ui/`](../docs/design/board-ui/) 시안(`index.html`)을 따릅니다.

- 사이드바, 상단 도구(카드/분류 보기, 분류하기, 메모 찾기, 확대·축소), 격자 캔버스, 오른쪽 도구 창(선택·이동·메모지·표시)
- 빈 보드에서 바로 쓰기: `Enter` 메모지로 붙이기, `Shift + Enter` 줄바꿈, 한글 조합 중 `Enter`는 무시
- 빈 곳을 두 번 클릭하거나 `메모지` 도구로 누른 자리에서 쓰기, 메모지를 두 번 클릭해 고치기
- 메모지를 누르면 나오는 도구로 편집·표시·삭제(카드 보기), 다른 주제로 옮기기(분류 보기), 분류 보기에서 끌어서 옮기기
- 분류 결과를 주제별 줄로 표시하고 미분류는 맨 아래 회색 줄에 따로 표시, 주제 접기·펼치기, 주제 이름 고치기, 새 주제 만들기
- 화면을 열면 서버 보드를 바로 불러오고, 불러오는 중/서버 연결 실패/보드 없음 상태를 표시
- 분석 중 표시와 조작 잠금, 분석 실패(503·409·시간 초과) 시 기존 보드를 그대로 두고 `다시 시도` 제공
- B2 카드 생성·수정·삭제, B3 그룹 생성·이름 변경·카드 이동, B5 AI 분석 API는 `useIdeaBoard` 훅을 그대로 사용
- 여러 개 한 번에 입력(최대 50개, 중복·길이 검증)

## 검증

```bash
npm run test
npm run lint
npm run build
npm run test:e2e
```

`npm run test:e2e`는 5174 포트에 개발 서버를 따로 띄우고, 백엔드 API 응답은 `e2e/fake-api.ts`가 대신합니다. 백엔드를 켜 둘 필요가 없습니다.

## 시안 중 미연결 기능

현재 API·DB 계약에 저장할 곳이 없거나 별도 작업으로 나눈 기능입니다.

- **메모지 위치(x/y):** API에 좌표 필드가 없어 이 브라우저의 `localStorage`에만 저장합니다. 다른 브라우저나 팀원 화면에서는 기본 격자 순서로 놓입니다.
- **펜 도구:** 그린 선을 저장할 곳이 없어 도구 창에서 뺐습니다.
- **표시(별):** 서버 필드가 없어 이 브라우저에만 저장합니다.
- **공유:** 공유 권한·링크 API가 없어 버튼만 두고 비활성화했습니다.
- **새로운 메모 보드 만들기·프로젝트·최근 항목 목록:** 보드 목록 화면은 별도 작업입니다. 지금은 `.env.local`의 `VITE_BOARD_ID` 보드 하나를 엽니다.
- **로그인·회원가입·계정 메뉴:** 별도 작업입니다. 사이드바 아래에는 계정 대신 저장 상태와 `서버에서 새로고침`을 둡니다.
