# Idea Hub 프런트엔드

아이디어 카드 담당 범위(U1~U6)를 React + TypeScript로 구현한 보드입니다.

## 실행

```bash
npm install
npm run dev
```

기본값은 브라우저 `localStorage`에 저장되는 로컬 모드입니다. 백엔드를 연결하려면 `.env.example`을 `.env.local`로 복사하고 API 주소와 보드 ID를 설정합니다.

## 구현 범위

- 카드 생성·수정·삭제
- 최대 50개 아이디어 일괄 입력과 중복·길이 검증
- 검색, 그룹 필터, 즐겨찾기
- 그룹 생성·이름 수정, 드래그 앤 드롭 및 선택 메뉴를 통한 카드 이동
- B2/B3 계약을 따르는 REST API 어댑터와 로컬 저장 폴백
- 도메인·API·주요 UI 흐름 테스트

## 검증

```bash
npm run test
npm run build
```

현재 백엔드 `B2`는 별도 브랜치에서 개발 중이고 `B3` 그룹 API는 아직 준비되지 않았습니다. 로컬 모드에서는 모든 기능이 동작하며, 원격 모드에서는 서버에 구현된 엔드포인트부터 동기화됩니다. 원격 저장 실패 시 로컬 변경은 유지되고 화면 상단에 오류가 표시됩니다.
